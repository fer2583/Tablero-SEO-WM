# Tablero SEO WM

Dashboard Next.js para Whalemate. Incluye una integración mínima de solo lectura con Google Search Console y GA4, manteniendo datos mock como fallback.

## Desarrollo

```bash
npm install
npm run dev
```

Consulta [docs/QUICK-CONNECT.md](docs/QUICK-CONNECT.md) para crear la service account, dar permisos, configurar variables locales o Vercel y validar las conexiones.

```bash
npm run lint
npm run build
```
